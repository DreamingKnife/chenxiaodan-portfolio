## 打开方式

### 本地查看
直接在浏览器中打开 `作品集首页.html`，所有单品可通过首页卡片跳转。

### GitHub Pages 部署
1. 本仓库已上传至 `DreamingKnife/chenxiaodan-portfolio`
2. 在仓库 Settings → Pages 中启用，选择分支后保存
3. 页面结构在此文件夹内，仅需平铺文件到仓库根目录，GitHub Pages 会自动将 `作品集首页.html` 作为入口（或将其重命名为 `index.html`）

## 技术实现

- **纯前端**：HTML5 + CSS3 + Vanilla JavaScript，无框架、无构建工具
- **Canvas 动效**：首页 Canvas 星空粒子背景、单品 3 的 2D 游戏引擎
- **完全内嵌**：所有 CSS / JS / 字体 / 图片均以 `data:` URI 或 `<style>` / `<script>` 块内联于单个 HTML 文件中
- **响应式设计**：移动端适配，支持虚拟摇杆等触控交互
- **设计系统**：统一 Design Token（暗色天文主题）、CSS 变量驱动、`Space Grotesk` + `Inter` 字体

## ⚠️ 关于大文件

`videos/v3_jianwang3.mp4` 约 300 MB，**超过 GitHub 100 MB 单文件限制**。如果你 clone 后发现视频缺失，是因为该文件使用了 Git LFS。请先安装 [Git LFS](https://git-lfs.com/)，然后：

```bash
git lfs install
git lfs pull
```
